## 🎯 Interview Preparation Strategy

For every problem, follow this process:

| Step | What to Do |
|:---:|---|
| 1️⃣ | Understand the problem and clarify edge cases. |
| 2️⃣ | Try solving it independently before looking at solutions. |
| 3️⃣ | Write clean, readable Python code. |
| 4️⃣ | Test with normal inputs and edge cases. |
| 5️⃣ | Analyse time and space complexity. |
| 6️⃣ | Explain your approach as if you were in an interview. |
| 7️⃣ | Connect the problem to a real-world GenAI use case where applicable. |

---

## 🧠 Key Areas to Master for GenAI Interviews

Beyond solving these 40 problems, make sure you understand:

- **Python Fundamentals:** Mutable vs immutable, shallow vs deep copy, `*args`, `**kwargs`.
- **Data Structures:** Lists, tuples, sets, dictionaries, stacks, and queues.
- **Python Internals:** Iterables, iterators, generators, decorators, and the GIL.
- **Asynchronous Programming:** `async`, `await`, `asyncio`, and concurrent API calls.
- **Backend Development:** FastAPI, REST APIs, JSON handling, exception handling, and logging.
- **GenAI Engineering:** Chunking, embeddings, cosine similarity, Top-K retrieval, and batch processing.
